Salamandra SN Report Generator

Salamandra 維修紀錄：輸入 SN、Station、Error Code、Status 及 SUB-BIN，再產生可直接貼到聊天群的報告。

資料

JTAG 顯示 JTAG/CVF；FT 顯示 FT 測試項目；LC245 可自訂 Error Code。
提示：每一行代表一個維修步驟。先選動作，再填出現的零件或結果欄位；不確定分類時可選「自訂輸入」。
先選擇「檢查／測試」，再選擇「維修／處理」；需要調整順序時，使用 ↑ ↓ 按鈕。

改版資訊
V106
修正「從輸出回填欄位」：Error Code 會正確回填；Still Failed 狀態不再變回 Pass；NTF 不再重複新增 Check out；RC35／RC56／RC48 及零件會保留；新增 Assemble、Cable、帶補充資訊的 Reburn JTAG／Retest DFT／ICT 回填。修正 Need RE 帶入已換 Harness 零件時型號遺失，導致「Harness 尚未選擇型號」而無法產生報告（步驟多時較常發生）。
V105
修正 Harness 型號選單被「補充位置／編號」欄位蓋住的問題：Replace／Reassemble／Assemble／Need RE 的零件欄位改為自動往下排列，不再重疊。
V104
修復 Replace／Reassemble／Assemble 的 Harness 型號選單顯示；Check 欄位改為兩行排列，減少手機版擁擠。
V101
修正 iPhone 版 ICT Status／Board／Pass／刪除按鈕欄位重疊，重新設定固定 Grid 欄寬、縮小左右間距並支援窄螢幕。
V99

V98
Reburn JTAG／Retest DFT 新增可選補充欄位並輸出到報告；統一 Replace、Reassemble、Assemble 的 Pass／Still Failed 按鈕位置；Assemble 新增 Pass／Still Failed 按鈕與輸出狀態。
V97
修正 ICT 列的 CSS 選擇器，避免將隱藏的 Further debug 按鈕誤顯示成 ICT 結果；重新調整手機版 Status、Board、Pass／Fail 與刪除按鈕寬度。
V96

V93

V90
