JTAG 顯示 JTAG/CVF；FT 顯示 FT 測試項目；LC245 可自訂 Error Code。
提示：每一行代表一個維修步驟。先選動作，再填出現的零件或結果欄位；不確定分類時可選「自訂輸入」。

改版資訊
V90
修正 RC48 零件選單輸出：選單所選零件會保留，補充欄位作為型號／位置附註；回填時可解析「零件＋補充內容」。
V89
產生報告後自動複製完整報告到剪貼簿，並顯示成功／失敗提示；保留手動「複製全部」按鈕作為備援。
V88
手機介面整理：所有下拉選單加明顯箭頭、FT Error Code 依 Stress／IB Link、OSFP、Monitoring、ASIC／BIST、Power／PCIe、Physical Security 分組；新增產生前欄位檢查與本機自動暫存／恢復。
V87
修正 TOP 32 中數字開頭的 CVF Error Code 分類：180、188 移至 JTAG / CVF 選單，不再出現在 FT；數字開頭的 CVF 項目統一歸類 JTAG。
V86
依據最新 Error Code TOP 32 統計，新增尚未收錄的 FT Error Code，涵蓋 Stress、IB Link、OSFP、ASIC、PCIe、Monitoring、Physical Security、LBIST 等項目；保留原始 Error Code 字串供報告輸出。
V85
修正切換維修動作後 Harness 型號選單／補充欄位未重新顯示；移除會強制隱藏 Harness 型號選單的手機版樣式；修正 Need RE to assemble 讀取 Harness 型號時的欄位作用域。
V84
所有維修類型選擇 Cable 時只顯示一個編號輸入欄；修正 Need RE to assemble、Reassemble、Replace／Need RE to change 的 Cable 輸出一致性；Harness 型號選單維持適用於 Replace、Reassemble、Need RE to change、Need RE to assemble。
V83
修正 Harness 選擇 3 harness 時的輸出格式（Replace 3 harness，不重複 harness）；Status 同時包含 NTF 與 Check out 時自動選擇 RC35；同步更新頁尾版號。
V93
選擇 NTF 時若尚未有 Check out，會自動新增第二筆 Status 並選取 Check out，讓 RC35 自動判定。
V82
修正 Need RE to assemble 零件帶入與多零件處理。
V81
零件選單與補充欄位改為同一行排列，減少手機畫面空白；Harness 改為主選單＋型號選單（3 harness／HAR002261／HAR002265／HAR002262），選 3 harness 不重複輸出。
V77
修正 Replace 換板後自動追加 Reburn JTAG 的問題；只有 Need RE to change 的 reburn JTAG 勾選項會控制是否輸出。
V76
新增可展開／收合的改版資訊，點擊「改版資訊」查看版本紀錄。
V75

V74
